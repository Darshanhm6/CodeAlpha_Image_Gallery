# 📸 Image Gallery

A modern, responsive, and interactive **Image Gallery Web Application** developed as part of the **CodeAlpha Web Development Internship**. The application allows users to browse, view, and navigate through a collection of images with a clean and attractive interface.

## 🌟 Project Overview

The **Image Gallery** is designed to provide a simple and smooth way to display and explore images on a website. It uses front-end web technologies to create an interactive gallery that works across different screen sizes.

The project focuses on:

* Responsive web design
* Interactive user interface
* Image browsing and preview
* Simple and clean layout
* Smooth user experience

## ✨ Features

* 🖼️ Display multiple images in a gallery
* 🔍 View images in an enlarged preview
* ⬅️ Previous image navigation
* ➡️ Next image navigation
* ❌ Close image preview
* 📱 Responsive design for mobile, tablet, and desktop
* 🎨 Clean and attractive user interface
* ⚡ Fast and lightweight application
* 🖱️ Interactive image selection
* 📐 Flexible gallery layout

## 🛠️ Technologies Used

## 💻 How It Works

1. The images are displayed in a responsive gallery layout.
2. Users can select an image to view it in a larger preview.
3. The **Next** and **Previous** buttons allow users to navigate between images.
4. The preview can be closed to return to the gallery.
5. CSS media queries ensure that the gallery adapts to different screen sizes.

## 📱 Responsive Design

The application is designed to work on:

* 💻 Desktop
* 💻 Laptop
* 📱 Mobile
* 📲 Tablet

The layout automatically adjusts according to the screen size for a better user experience.
